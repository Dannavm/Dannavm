### Experiencia y Logros

Me he especializado en transformar requerimientos complejos en sistemas funcionales, tanto en la interfaz como en el servidor:

- **Sistemas de Salud (Funcrisa):** Desarrollo Full-Stack de un sistema de gestión clínica con Next.js, React y NestJS. Sesión segura con JWT y renovación automática de tokens, dashboards estadísticos, validaciones con React Hook Form y Zod, y modo claro/oscuro.
- **Back-End (NestJS, TypeORM, PostgreSQL):** Migraciones reversibles, validaciones con DTOs, historial de cambios mediante auditoría, subida segura de archivos (validación por contenido y límite de tamaño), y pruebas e2e con Vitest.
- **Sistemas Empresariales (ERP):** Vistas analíticas interactivas en Angular/TypeScript (incluido un "Modo TV" para dashboards gerenciales), mantenimiento de módulos de logística, inventario, ventas y SAC en Visual FoxPro, consultas avanzadas en SQL Server y más de 80 tickets de soporte resueltos.
- **Diseño UI/UX:** Diseños responsivos, accesibles y con validaciones robustas de datos.
